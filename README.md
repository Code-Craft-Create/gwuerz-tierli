# Gwürz Tierli

Es chliises Siitli, wo süessi Kosenäme generiert: es Gwürz + es Tierli, z.B. **Zimt-Schnäggli** oder **Honig-Bärli**.

- `index.html` – d Siite
- `woerter.js` – d Wörterlischte (Gwürz und Tierli)

Lauft als statischi Siite uf GitHub Pages (Branch `main`, Ordner `/`).

D Version stoht zunderst uf de Siite (`.version` in `index.html`) und wird bi jedem Release ufezellt.
